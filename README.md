#### 🧠 [NLP Context-Free Grammar (CFG) Sentence Parser](https://github.com/PranavBhatt-pb/NLP-Sentence-Parser)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square)
![NLTK](https://img.shields.io/badge/Library-NLTK-green?style=flat-square)
![Theory](https://img.shields.io/badge/CS%20Theory-Context--Free%20Grammars-orange?style=flat-square)

- **Academic Foundation:** Grounded in Automata Theory, Formal Language Theory, and Computational Linguistics.
